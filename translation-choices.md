# Translation Choices

A working glossary of deliberate English renderings for this study's own
translation. **Starts from `canon-conventions.md`** (a vendored copy of `bible-core/canon/conventions.md`; don't edit it here): every row
there is this book's default too (y'all, Yahweh, sky/skies, slave, life/being,
look, chest, covenant, devote to destruction, inheritance, ḥesed untranslated,
…). This file records only what Leviticus decides for itself, including any
deviation from a canon default and the reason.

## How to use this file

Before rendering a word in a new unit, check here and in the canon conventions
and match a prior decision. If a different rendering fits better in one verse,
use it and flag the deviation; Lane decides whether it's a one-off or a
correction. A chat records a decision in the handoff's "Decisions"; Claude Code
updates the row and the Log. If a unit and this file disagree, flag it: the
unit is more likely right.

## Glossary

| word | Hebrew (translit.) | rendering | note |
|---|---|---|---|
| kipper | kipper | **cover**; with ʿal + person, "cover for" (4:26) | Literal image, chosen over "make atonement" and Milgrom's "purge"; the notes carry the purge/expiate sense. |
| Yom Kippurim | yom hakkippurim | **Day of Coverings** | Plural as in the Hebrew (23:27–28, 25:9); the traditional "Day of Atonement" is named once in a note. |
| sin offering | ḥaṭṭaʾt | **sin offering** | Keeps the link to "sin" (4:3, 16:16). A note at 12:6 and ch. 14 says no sin is in view there (Milgrom: purification offering). |
| guilt offering | ʾasham | **guilt offering** | Matches the "he is guilty" verb (5:2–5). The repayment plus a fifth (5:16, 6:5) goes in the notes. |
| going up offering | ʿolah | **going up offering** | Tracks ʿalah, "go up": what rises in smoke (1:9). |
| qorban | qorban | **brought near offering** / **coming near offering**, as context suggests | Keeps the link to hiqriv, "bring near" (1:2). |
| unclean/clean | ṭameʾ / ṭahor | **unclean / clean** | Links to Matthew's "cleanse" (katharizō). A ritual state, not dirt or sin. |
| flaking | tsaraʿat | **flaking** ("a mark of flaking") | One noun for skin, cloth, leather and walls. Not Hansen's disease; a note at 14:34 says on walls it looks like mould; Matthew's "leprosy" is the same word in Greek. |
| cut off | karet | **cut off from his people** | Leaves death, exile or loss of line as open as the text does. |
| holy, set apart | qadash family | canon default: **holy** (adj., noun), **set apart** (verb) | As locked in Joshua 3:5. The root link in 19:2 / 20:8 goes in a note. |
| kinsman redeemer | goʾel | **kinsman redeemer** (noun, ch. 25); verb gaʾal **redeem**, geʾullah **redemption** | Ch. 27 has only the verb and noun, so "redeem" serves there. The canon question (Num 35 "avenger of blood") stays open in core. |
